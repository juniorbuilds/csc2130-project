About BizTrack

BizTrack is a Progressive Web App (PWA) designed to help small and medium-sized businesses manage their operations digitally. It was built using pure HTML5, CSS3, and Vanilla JavaScript — with no frameworks required — making it lightweight, fast, and installable on any device.

This project was developed as part of the CSC2130 – Introduction to Web Development course at Kibabii University. The goal was to solve a real business problem: giving small traders access to professional-grade stock and profit management tools without the cost of expensive software.

Our Mission

Our mission is to empower small business owners with simple, affordable, and offline-capable digital tools. Many small traders in Kenya and across Africa still manage their records in handwritten books, which makes it difficult to track profit, monitor stock, and plan for growth. BizTrack aims to replace paper-based record keeping with a modern, easy-to-use web application.

Our Vision

Our vision is to become the most trusted business management tool for micro and small enterprises across East Africa. We envision a future where every market trader, shop owner, and small entrepreneur has access to real-time profit insights, instant stock alerts, and data-driven decision making — all from their smartphone.

How to Use BizTrack

Step-by-step guide for new users

  1. Open BizTrack in your browser or install it as an app on your Android/iOS device from the browser menu
  2. Navigate to the Stock page and add all your products with their buying price, selling price, and current quantity
  3. Set a minimum stock alert level for each product so the app warns you before you run out
  4. Go to the Sales page and click "Record Sale" each time you sell goods — select the product, quantity, and confirm the price
  5. The app automatically calculates your profit per item and deducts the sold quantity from your stock
  6. Log any business costs (rent, salaries, transport) under the Expenditures page
  7. Visit the Reports page to view your complete Profit & Loss statement, top-selling products, and monthly trends
  8. Use the Dashboard daily to monitor stock alerts, recent sales, and net profit at a glance

Technical Glossary

Key terms used in this project

PWA
Progressive Web App — a web application that can be installed on a device and works offline like a native app
HTML5
HyperText Markup Language version 5 — the standard language used to structure content on the web
CSS3
Cascading Style Sheets version 3 — used to control the visual presentation and layout of HTML elements
JavaScript
A scripting language that makes web pages interactive, handling user events and dynamic content updates
localStorage
A browser API that allows web applications to store data on the user's device without needing a server
Service Worker
A background script that enables a PWA to cache files and function offline, intercepting network requests
Semantic HTML
Writing HTML using meaningful elements (like <header>, <nav>, <article>) that describe the content's purpose
Manifest.json
A JSON file that tells the browser how to display the app when installed, including its name, icon, and theme colour

Technology Stack

  • Front-end
    • HTML5 — semantic page structure across all modules
    • CSS3 — custom dark theme, grid layout, animations
    • JavaScript (ES6+) — app logic, data management, UI rendering
  • Data Layer
    • localStorage — all records stored on-device
    • JSON — data serialisation format for all stored records
  • PWA Layer
    • manifest.json — installation configuration
    • sw.js — service worker for offline caching
    • Cache API — stores app assets for offline access
  • Deployment & Distribution
    • Netlify — free static hosting with drag-and-drop deploy
    • PWABuilder — convert PWA to Android APK
    • Google Play Store — optional app distribution (AAB format)
